## Perizinan Root
Anda harus memberikan akses root terlebih dahulu.

### * Magisk
Anda dapat memberikan akses root secara langsung di jendela pop-up saat mengklik
kartu izin.

### * KernelSU/APatch
Anda harus memberikan akses root secara manual di pengelola aplikasi tersebut
terlebih dahulu, lalu memulai ulang **DataBackup**.

### Custom su file
Pada beberapa perangkat, berkas `su` mungkin tidak bernama `su`, jadi Anda dapat
mengeditnya secara manual. Ingatlah untuk me-restart **DataBackup** agar
perubahan tersebut berlaku.
