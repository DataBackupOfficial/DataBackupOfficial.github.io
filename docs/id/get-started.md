# Memulai

[DataBackup](https://github.com/XayahSuSuSu/Android-DataBackup) adalah aplikasi
pencadangan data gratis dan sumber terbuka untuk Android 8+.

## Root

Aplikasi ini memerlukan root dan mendukung
[Magisk](https://github.com/topjohnwu/Magisk),
[KernelSU](https://github.com/tiann/KernelSU),
[APatch](https://github.com/bmax121/APatch).

## Install

Anda dapat memperoleh **APK** dari:
* **[Rilis](https://github.com/XayahSuSuSu/Android-DataBackup/releases)**
* **[F-Droid](https://f-droid.org/zh_Hans/packages/com.xayah.databackup.foss/)**
* **[IzzyOnDroid](https://apt.izzysoft.de/fdroid/index/apk/com.xayah.databackup)**

Ada 6 varian:
* **foss**: Dibangun tanpa [Firebase](https://firebase.google.com/).
* **premium**: Dibangun dengan [Firebase](https://firebase.google.com/).
* **[arm64-v8a](https://developer.android.com/ndk/guides/abis#arm64-v8a)**: ABI
  ini untuk CPU ARM 64-bit, **yang merupakan pilihan pertama bagi sebagian besar
  pengguna**.
* **[armeabi-v7a](https://developer.android.com/ndk/guides/abis#v7a)**: ABI ini
  untuk CPU ARM 32-bit. ABI ini mencakup Thumb-2 dan Neon.
* **[x86](https://developer.android.com/ndk/guides/abis#x86)**: ABI ini untuk
  CPU yang mendukung set instruksi yang umum dikenal sebagai "x86", "i386", atau
  "IA-32".
* **[x86_64](https://developer.android.com/ndk/guides/abis#86-64)**: ABI ini
  untuk CPU yang mendukung set instruksi yang umumnya disebut sebagai "x86-64".
  **Ini ditujukan bagi pengguna yang menggunakan emulator PC.**
