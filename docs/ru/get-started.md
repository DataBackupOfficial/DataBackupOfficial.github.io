# Начать работу

[DataBackup](https://github.com/XayahSuSuSu/Android-DataBackup) — это бесплатное
приложение с открытым исходным кодом для резервного копирования данных на
устройствах с Android 8 и выше.

## Root

Для работы этого приложения требуются права root; поддерживаются
[Magisk](https://github.com/topjohnwu/Magisk),
[KernelSU](https://github.com/tiann/KernelSU) и
[APatch](https://github.com/bmax121/APatch).

## Установить

Вы можете скачать **APK** по следующей ссылке:
* **[Выпуски](https://github.com/XayahSuSuSu/Android-DataBackup/releases)**
* **[F-Droid](https://f-droid.org/zh_Hans/packages/com.xayah.databackup.foss/)**
* **[IzzyOnDroid](https://apt.izzysoft.de/fdroid/index/apk/com.xayah.databackup)**

Существует 6 вариантов:
* **foss**: Создан без использования [Firebase](https://firebase.google.com/).
* **premium**: Создано с использованием
  [Firebase](https://firebase.google.com/).
* **[arm64-v8a](https://developer.android.com/ndk/guides/abis#arm64-v8a)**:
  Данный ABI предназначен для 64-разрядных процессоров ARM, **которые являются
  предпочтительным выбором для большинства пользователей**.
* **[armeabi-v7a](https://developer.android.com/ndk/guides/abis#v7a)**: Данный
  ABI предназначен для 32-разрядных процессоров ARM. Он включает в себя Thumb-2
  и Neon.
* **[x86](https://developer.android.com/ndk/guides/abis#x86)**: Данный ABI
  предназначен для процессоров, поддерживающих набор инструкций, широко
  известный как «x86», «i386» или «IA-32».
* **[x86_64](https://developer.android.com/ndk/guides/abis#86-64)**: Данный ABI
  предназначен для процессоров, поддерживающих набор инструкций, обычно
  называемый «x86-64». **Он предназначен для пользователей, использующих
  эмулятор ПК**
